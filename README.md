## 🔗 How to Use This Directory

1. **Browse** the previews above.
2. Click the **“Source Code”** link for any project.
3. On that repo, you can:
   - 🌟 **Star** it.
   - 🍴 **Fork** it to your account.
   - 📦 **Download ZIP** or `git clone` the code.
4. Customize the text, images, and colors, then deploy on GitHub Pages or your own host.
